============
SKK サーバー
============

接続について
============

TCPによる接続を受け付ける。
待ち受け用のポートは **1178** を標準とする。

また、単純なハンドシェイクを含めて、通信確立後とコマンド送受信の間に特別な処理は一切実施しない。

接続後の振舞い
==============

接続確立後は、クライアントからの通信を基点に処理をしていく。

サーバー側から能動的にクライアントへの通信をすることはない。
また、クライアントも自身のコマンド送信後はサーバーからの返信を待ち、
1サイクルが完結することなく次のコマンドを送信することはしない。

1. クライアントはサーバーに対してコマンドを送信する。
2. サーバーは受信したコマンドに応じて、返信する内容を算出する。
3. サーバーはクライアントに対して、組み立てた結果を送信する。
