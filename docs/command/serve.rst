``serve``
=========

SKKサーバープロセスを起動します。
通常時は指定した辞書ファイルをもとに変換候補を応答しますが、
オプションによっては別の手段を用いることが出来ます。

引数
----

使用するローカル辞書ファイルを指定します。

:doc:`./build` で作成した「統合済みUTF-8版辞書ファイル」を指定してください。

オプション
----------

--server-host
  サーバー起動時の受け付けホストを指定できます。
  デフォルトでは ``127.0.0.1`` です。
  ネットワーク内で同一サーバーを共有したい場合に設定してください。
--server-port
  サーバーの待ち受けポート番号を指定できます。
  デフォルトでは ``1178`` です。
