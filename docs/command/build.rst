``build``
=========

:doc:`./serve` で使用するための辞書ファイルを生成します。

atskkservの実装では変換候補となる辞書に次の条件を指定しています。

* ファイルは単体のみ指定可能。
* 事前に見出し語をソート済みであること。
* UTF-8の状態で保存されていること。

そのため、一般公開されている辞書ファイルはそのまま使用できません。
このコマンドを通して使用可能な形式に変換する必要があります。

引数
----

SKK辞書として使用したい統合対象元となるファイルのパスを指定します。
複数個のファイルパスを指定可能です。

オプション
----------

--force
  出力先にファイルが存在しても、上書き保存するようになります。
  デフォルトは ``false`` です。
--dest
  生成した辞書の出力先を指定します。
  指定しない場合は、カレントディレクトリに ``SKK-JISYO.utf-8`` を生成します。
