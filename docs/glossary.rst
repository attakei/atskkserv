======
用語集
======

主に「ここでちょっと変った使い方をしているかもしれない」というものを中心に、
ドキュメント内の説明に使用している単語につて説明をしています。

.. glossary::

   SKKクライアント
      atskkservをはじめとして、SKK辞書サーバーに接続して
      「見出しに対する変換候補」を要求するソフトウェアの総称。

      代表的なもの:

      * CorvusSKK (Windows向けIME)
      * AquaSKK (macOS向けIME)
      * skkeleton (Vim/NeoVimプラグイン)
